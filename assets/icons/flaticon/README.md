# Flaticon Icon Pack - Scholar

Emplacement des icônes SVG style Flaticon pour l'application Scholar.

**Implémentation :** Les icônes sont rendues via les composants React dans `@/components/icons/flaticon`.

## Style
- Contour / ligne arrondie (outline)
- Épaisseur de trait constante (stroke-width: 1.5)
- Minimaliste, propre, moderne
- `currentColor` pour le support light/dark mode

## Remplacer par des icônes Flaticon officielles
1. Télécharger depuis [Flaticon.com](https://www.flaticon.com) (style outline/line)
2. Respecter stroke-width 1.5, caps/joins arrondis
3. Mettre à jour le composant dans `components/icons/flaticon/index.tsx`

## Icônes disponibles
Dashboard, Users, GraduationCap, BookOpen, Hourglass, LayoutList, Calendar, CalendarCheck, HelpCircle, Settings, LogOut, Menu, X, PiggyBank, CheckSquare, Search, Filter, Download, TrendingUp, Bell, ChevronDown/Left/Right/Up, Eye, Trash, CheckCircle, XCircle, Clock, MessageSquare, AlertCircle, PanelLeft, Shield, Lock, Unlock, User, School, Check, Circle, MoreHorizontal, GripVertical, ArrowLeft/Right, Dot
